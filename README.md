ASK THE ARCHIVE
===============

Local-first AI organisational knowledge intelligence platform.

## Stack

- Next.js, TypeScript and Tailwind CSS
- FastAPI and SQLAlchemy
- PostgreSQL with pgvector
- Ollama
- Sentence Transformers
- Tesseract OCR
- PyMuPDF and python-docx

## Development

```bash
docker compose up --build
```

Services: frontend (3000), API (8000), PostgreSQL (5432), Ollama (11434).
